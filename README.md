# The AI Black Box: Responsible AI

This repository contains the curated datasets and visual assets for the research case study on **AI opacity, ethical risks, and Responsible AI governance**.

* **Author:** Selçuk Çelik
* **Blog Post:** [https://dataparadox.medium.com](https://dataparadox.medium.com)

## 📌 Overview

This study explores the systemic risks of algorithmic opacity ("black-box" systems) and tracks the global transition toward Responsible AI frameworks:

1. Growth in real-world AI incidents (2012–2025).
2. Model-specific hallucination benchmarks.
3. Enterprise risk perception vs. active mitigation gaps.
4. Internal governance ownership shifts.
5. Global AI legislative and regulatory momentum.

## 📁 Repository Structure

* **`data/`**: Contains all 6 curated CSV datasets used in the analysis.
* **`figures/`**: High-resolution static exports of all visualizations.
